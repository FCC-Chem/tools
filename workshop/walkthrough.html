One-time setup

~15 minutes · do this before the workshop
▶
Create a GitHub account at github.com with your school email — then click the verification link in your inbox.Unverified accounts can't create projects, and it fails silently. This is the #1 setup trap.
Confirm your AI access. Go to copilot.cloud.microsoft (or open Copilot in Teams or Edge) and sign in with your district Microsoft 365 account. Everyone at FCC already has this — no signup.Signed in with your work account, Copilot has enterprise data protection — your chats aren't used to train models. The three rules above still apply in full. Claude or ChatGPT work fine too if you prefer.
Accept the FCC-Chem invite when the email arrives (needed only for Phase 4 — the department catalog). It expires, so click it when you see it.

Build the tool with Copilot

~30 minutes · describing, not coding
▶
Pick one small idea: one screen, one job. A calculator, a converter, a practice widget.No files, no email, no student data. Small scope is the difference between done-in-30-minutes and stuck.
Paste the starter prompt into Copilot chat and fill in your idea:
Build me a complete single-file HTML page (all CSS and JavaScript inline, no external files except CDN libraries) that does: [DESCRIBE YOUR TOOL HERE]. It should work when I save it as index.html and open it in a browser. Show me the full file.
Iterate by describing, not coding. "The buttons are too small." "It calculated X wrong — the right answer is Y."If it breaks, paste the error message or a screenshot back into Copilot. Don't debug by hand — the AI does the code, you do the describing. That's the whole skill.
Test it in your browser. Copilot won't run the page for you: copy the full code → paste into TextEdit (Mac: Format → Make Plain Text first) or Notepad → save as index.html → double-click it. Repeat after each change.
Ask for the full file every time. If Copilot gives you a fragment, say: "Show me the complete updated index.html, whole file."
Stuck? Common fixes
Tool too ambitious → shrink to one input, one output, one screen.
Output broken → paste the exact error back into the chat.
Finished early → restyle it, or build a second tool.
2

Give it a home on GitHub

~10 minutes · "free hosting for one file"
▶
New repository: on github.com click + → New repository → name it your-tool-name → Public → Create repository.
Add your file: Add file → Create new file → name it exactly index.html → paste your code → Commit changes.
Turn on hosting: Settings → Pages → Source: Deploy from a branch → Branch: main, folder / (root) → Save.
Wait ~1 minute, then open your live URL:
https://YOUR-USERNAME.github.io/YOUR-TOOL/
404 or blank page?
Settings → Pages → confirm branch is main and folder / (root). Then wait the full minute — it's not instant. Still down? Confirm the file is named exactly index.html.
Know the update move (for later): open index.html on github.com → pencil icon → paste the new version → Commit. That's the entire maintenance workflow.
3

Embed it in Canvas

~5 minutes
▶
Canvas page → Edit → </> (HTML editor) → paste:
<iframe src="https://YOUR-USERNAME.github.io/YOUR-TOOL/" width="100%" height="600"></iframe>
Save the page and check it renders.
Iframe shows blank?
Open your live URL by itself first — if the standalone page is broken, the iframe will be too. Fix the tool, then re-check the Canvas page.
4

Submit to the department catalog

later, when a tool earns it · your account is the workshop, the dept repo is the trophy case
▶
Check the four hard rules one last time: no student data · no credentials · no answer keys · nothing copied from a publisher. Public repos are permanently mirrored — deleting later does not undo it.
Add your tool: in github.com/FCC-Chem/tools → Add file → Create new file → type yourlastname/your-tool/index.html (each / creates a folder) → paste your code → Commit.
Optional — better catalog card: repeat for yourlastname/your-tool/meta.json, copying the format from _template/meta.json (title, one-sentence description, course, tags).
Wait ~1 minute → your tool appears on fcc-chem.github.io/tools/, credited to you automatically. Done — you've shipped a department teaching tool.
