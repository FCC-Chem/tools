Build the tool with Copilot

~30 minutes · describing, not coding
▶
Pick one small idea: one screen, one job. A calculator, a converter, a practice widget.No files, no email, no student data. Small scope is the difference between done-in-30-minutes and stuck.
Paste the starter prompt into Copilot chat and fill in your idea:
Build me a complete single-file HTML page (all CSS and JavaScript inline, no external files except CDN libraries) that does: [DESCRIBE YOUR TOOL HERE]. It should work when I save it as index.html and open it in a browser. Show me the full file.
Iterate by describing, not coding. "The buttons are too small." "It calculated X wrong — the right answer is Y."If it breaks, paste the error message or a screenshot back into Copilot. Don't debug by hand — the AI does the code, you do the describing. That's the whole skill.
Test it in your browser. Copilot won't run the page for you: copy the full code → paste into TextEdit (Mac: Format → Make Plain Text first) or Notepad → save as index.html → double-click it. Repeat after each change.
Ask for the full file every time. If Copilot gives you a fragment, say: "Show me the complete updated index.html, whole file."
Show me exactly how to save it (Mac / Windows)
Copy first: hover over Copilot's code block → click its Copy button (don't drag-select; you'll miss lines).

Mac (TextEdit):
  1. Open TextEdit → new document → Format → Make Plain Text (⇧⌘T) before pasting. This matters: rich-text mode silently converts quotes to curly ones and breaks the code.
  2. Paste → File → Save → name it index.html → uncheck "If no extension is provided, use .txt" → Save → choose Use .html if asked.
Windows (Notepad):
  1. Open Notepad → paste → File → Save As.
  2. File name: index.html · Save as type: All Files (not .txt) · Encoding: UTF-8 → Save.
Then double-click the saved file — it opens in your browser. If it opens in a text editor instead, the file got saved as index.html.txt — redo the Save As with type "All Files".

Before you script

~10 minutes · Python, a folder, a sandbox
▶
Confirm Python 3 is installed. Open your terminal and run the line below — any version 3.8+ is fine.
python3 --version
Show me exactly where to type this (Mac / Windows)
The terminal is just a text box where you type instructions to your computer. It looks intimidating; it's a text box.

Mac:
  1. Hold ⌘ (command) and tap space → a search bar appears → type Terminal → Enter.
  2. A window opens with a blinking cursor. Click in it, paste the line above (⌘V), press Enter.
  3. Success looks like: Python 3.12.4 (any 3.8-or-higher number). That's it.
  4. "command not found"? Install from python.org/downloads (big yellow button, then keep clicking Continue/Agree/Install) → close the Terminal window, open a fresh one, try again.
Windows:
  1. Press the Windows key → type cmd → Enter. A black window opens — that's Command Prompt.
  2. Type python --version (no "3" on Windows) → Enter.
  3. Success looks like: Python 3.12.4.
  4. Nothing prints, or the Microsoft Store opens? That's Windows' decoy Python. Install the real one from python.org/downloads — and on the installer's FIRST screen, tick the checkbox "Add python.exe to PATH" before clicking Install. Then close the black window, open a fresh one, try again.
Truly stuck? You don't need Python at all — the Colab lane in Phase 4 runs everything in the browser.
Install the one library this needs:
python3 -m pip install requests
Windows: python -m pip install requests. This is the only dependency — everything else is standard Python.
What this does + what success looks like
It downloads one free helper library ("requests") that lets Python talk to websites. Type it in the same terminal window from the previous step.

Success looks like: a few lines ending in Successfully installed requests-… — or Requirement already satisfied, which is also success (it was already there).
A yellow "notice: a new release of pip is available" at the end is an advertisement, not an error — ignore it.

The token — highest-stakes 15 minutes

generate once · store once · never anywhere else
▶
Generate your token: Canvas → Account → Settings → scroll to Approved Integrations → + New Access Token → Purpose: API scripting workshop → set an expiration date (end of semester is plenty) → Generate.The token is shown once. Keep the window open until the next step is done.
Show me exactly where to click in Canvas
  1. In Canvas, far-left dark rail → Account (your picture or initials at the top) → Settings.
  2. Scroll down — past "Ways to Contact" and the feature checkboxes — to the section headed Approved Integrations.
  3. Click the + New Access Token button.
  4. A dialog opens. Purpose: type API scripting workshop. Expires: click the calendar icon → pick a date near the end of the semester. Don't leave it blank — a token that never expires is a token you'll forget you have.
  5. Click Generate Token.
  6. The next dialog shows your token: the long scramble of letters and numbers after Token:. Select all of it (triple-click usually grabs the whole thing) → copy (⌘C / Ctrl-C).
  7. Don't close this dialog yet. Canvas never shows this token again. Do the next step (paste into .env), then come back and close it.
  8. Copied it wrong, or lost it? Zero harm: back in Approved Integrations, click the trash icon on that token and generate a fresh one. The old one dies instantly — that's also the emergency move if a token ever leaks.
Create your .env file — in your scripts folder, make a plain-text file named exactly .env and paste, replacing the placeholder with your real token:
CANVAS_TOKEN=paste-your-token-here CANVAS_URL=https://scccd.instructure.com SANDBOX_COURSE_ID=YOUR-COURSE-ID
Show me exactly how to save a .env file (Mac / Windows)
Mac (TextEdit):
  1. Spotlight (⌘-space) → TextEdit → New Document.
  2. Format → Make Plain Text (⇧⌘T) before pasting — rich-text mode silently curls the quotes and breaks the file.
  3. Copy the three lines above → paste → replace paste-your-token-here with your real token (⌘V from the Canvas dialog). No spaces around the = signs.
  4. File → Save → name it env.txt → save into Documents/canvas-scripts.
  5. Now the rename to .env — open Terminal, paste this one line, press Enter:
mv ~/Documents/canvas-scripts/env.txt ~/Documents/canvas-scripts/.env
  1. The file vanishes from Finder — that's normal. Mac hides any file starting with a dot. It's still there (press ⇧⌘. in Finder to peek at hidden files; same keys to hide again), and the script will find it.
Windows (Notepad):
  1. Start → Notepad → copy the three lines above → paste → replace paste-your-token-here with your real token. No spaces around the = signs.
  2. File → Save As → navigate to Documents\canvas-scripts.
  3. File name: type ".env" including the quotation marks — the quotes stop Notepad from tacking on .txt.
  4. Save as type: All Files → Save.
  5. Check it worked: in File Explorer the file is named .env with type "ENV File". Seeing .env.txt? Delete it and redo Save As — the quotes were missing.
Close the Canvas token window. The token now exists in exactly two places: Canvas's memory and your .env. That's the whole system — check this box as your acknowledgment of the three rules at the top of this path.

First contact

~15 minutes · prove the connection before anything writes
▶
Shared dept sandbox only: in the Canvas UI, create an assignment named API-TEST-yourlastname (any due date, unpublished is fine). That's the only thing your script will ever touch.Personal sandbox? Skip this — but make sure your sandbox has at least one assignment to practice on.
Save the starter script as canvas_tool.py in your scripts folder (same folder as .env):
"""canvas_tool.py — FCC Chem starter script. THE THREE TOKEN RULES: never in a repo, never hardcoded, never in an AI chat. Leaked = revoke in Canvas immediately. This script reads the token from .env — it contains no secret, so the script itself is safe to paste into an AI chat.""" import os, sys from pathlib import Path import requests # --- load .env from this script's folder --- env = Path(__file__).resolve().parent / ".env" if not env.exists(): sys.exit("No .env found next to this script — do Phase 1 first.") for line in env.read_text().splitlines(): line = line.strip() if line and not line.startswith("#") and "=" in line: k, v = line.split("=", 1) os.environ.setdefault(k.strip(), v.strip()) TOKEN = os.environ.get("CANVAS_TOKEN") URL = os.environ.get("CANVAS_URL", "https://scccd.instructure.com").rstrip("/") COURSE = os.environ.get("SANDBOX_COURSE_ID") if not TOKEN or "paste-your" in TOKEN or not COURSE: sys.exit("Fill in CANVAS_TOKEN and SANDBOX_COURSE_ID in .env first.") H = {"Authorization": "Bearer " + TOKEN} # --- Section 1: connectivity proof (a read — changes nothing) --- r = requests.get(URL + "/api/v1/courses/" + COURSE, headers=H) r.raise_for_status() print("Connected to:", r.json()["name"]) # --- Section 2: list assignments --- r = requests.get(URL + "/api/v1/courses/" + COURSE + "/assignments", headers=H, params={"per_page": 50}) r.raise_for_status() assignments = r.json() if not assignments: sys.exit("No assignments here yet — create one in Canvas, then rerun.") for i, a in enumerate(assignments): print("[" + str(i) + "]", a["name"], "· due:", a.get("due_at") or "none") # --- Section 3: dry run, confirm, then change ONE due date --- pick = input("\nNumber of the assignment to change" " (dept sandbox: ONLY the one with your name), or Enter to quit: ").strip() if pick == "": sys.exit("Stopped after the read-only sections. Nothing was changed.") a = assignments[int(pick)] new_due = input("New due date (YYYY-MM-DD): ").strip() + "T23:59:00Z" print("\nDRY RUN — this is what the script is ABOUT to do:") print(" course: ", COURSE) print(" assignment:", a["name"]) print(" due date: ", a.get("due_at") or "none", " ->", new_due) if input('Type YES to make this change for real: ').strip() != "YES": sys.exit("Cancelled. Nothing was changed.") r = requests.put(URL + "/api/v1/courses/" + COURSE + "/assignments/" + str(a["id"]), headers=H, json={"assignment": {"due_at": new_due}}) r.raise_for_status() print("Done. Refresh the assignment in Canvas and look at the due date.")
Save it the same way as the .env (plain text, correct name) — or paste it into your AI chat and say "explain this to me line by line" first. That paste is safe: no secret in the script.

401? 404? Other errors?
401 Unauthorized → token pasted wrong in .env (extra space, missing character) or already expired/revoked.
404 Not Found → wrong course ID — recheck the number in your sandbox's URL.
ModuleNotFoundError: requests → redo the pip install (Phase 0).
Anything else → paste the full error into your AI chat. The error, not the token.

No Python on your machine? The Colab lane
Google Colab runs Python in the browser — zero installs, needs a Google account. Two changes from the local flow:

1. No .env file. The notebook asks for your token at runtime and holds it only in memory:
from getpass import getpass
TOKEN = getpass("Paste your Canvas token: ")

2. Nothing is stored — closing the notebook forgets the token; you paste it again each session. The token still never gets typed into a chat, saved in the notebook file, or shared. Slightly slower loop, zero install — it's the escape hatch, not the main road.
