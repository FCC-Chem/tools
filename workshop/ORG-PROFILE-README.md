# How to use this file

This is the **organization profile README** — the text that shows on
`github.com/FCC-Chem` when anyone visits.

It does **not** go in the `tools` repo. It goes in a separate repo named
exactly `.github`.

Setup (one time, ~2 min):

```bash
gh repo create FCC-Chem/.github --public --clone
cd .github
mkdir -p profile
# copy the content below into profile/README.md
git add . && git commit -m "Org profile" && git push
```

# FCC Chemistry

We build small teaching tools with AI, and we share them.

### 🧪 [Browse the tool catalog →](https://fcc-chem.github.io/tools/)

Every tool is a single web page. Click a link, it works. Nothing to install,
on any operating system, including a student's phone.

---

**What we're doing here**

Faculty in the Fresno City College chemistry department are learning to use
AI assistants to build the small utilities that make teaching easier —
calculators, simulations, visualizations, graders. Then we hand them to each
other and adapt them.

The tools are the byproduct. The skill is the point.

**Want in?**

- [Tool catalog](https://fcc-chem.github.io/tools/) — use them
- [Discussions](https://github.com/FCC-Chem/tools/discussions) — ask, share, argue
- [Request a tool](https://github.com/FCC-Chem/tools/issues/new) — describe what you need
