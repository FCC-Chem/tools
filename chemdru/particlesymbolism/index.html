How to use

  1. Drag atoms from the palette onto the canvas.
  2. Click an atom to select it (yellow ring).
  3. Click a second atom to bond them (or unbond if already connected).
  4. Drag atoms on the canvas to move them.
  5. Double-click an atom to delete it.

Tips

• Same element bonded → still an element (e.g. O2)
• Different elements bonded → compound (e.g. H2O)
• Several identical molecules → still pure element or compound
• Different formulas present → mixture
• Formulas use atom counts for each connected molecule.
