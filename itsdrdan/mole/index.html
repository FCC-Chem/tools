Mole Conversion Study Game

Use this study tool to practice mole conversions one skill at a time or mix several skills together. Choose the course level that matches your class, then work each problem using dimensional analysis.

📋 How to Use the Study Game
1

Choose your course. CHEM 3A uses shorter 1–2 step conversions; CHEM 1A includes longer and more advanced problems.

2

Select a practice type and, when available, the number of conversion steps you want to practice.

3

Solve the problem. Enter the final answer with the correct significant figures. In the CHEM 3A Builder, drag factors into place and use Flip when a fraction needs to be inverted.

4

Check your work. Use Hint or Show Solution when needed, open the Yellow Sheet Reference for atomic masses, and select New Question to keep practicing.
