Symbol Safari

Pick a tile, then type the symbol or name. Capital letters count.

How to play
  • Pick one or more tiles below. Mix them for mixed practice, or take Skill Check Prep for a 10-question quiz and a study plan.
  • Typing symbols: first letter capital, second letter lowercase (Co is cobalt, CO is carbon monoxide). Names can be any case, and British spellings like aluminium, sulphur and caesium count.
  • Where is it? questions use the periodic table: tap an element, check what you tapped, then press Check.
  • Stuck? Use Hint, Step by step or Show answer. Missed elements go to your review list, and the game asks them more often.
  • Use the CHEM 3A / CHEM 1A switch at the top. CHEM 3A focuses on the first 20, the health-science (body) elements and common ions. CHEM 1A adds the rest of the main group and common transition metals.
